# ms-MY v6.2.0 — Pek Bahasa Melayu untuk Joomla 6.2 (Site)

**Fail / Asset:** `ms-MY.zip` (pek bahasa laman / site language pack) **Sesuai untuk / Compatible with:** Joomla 6.2.x (disusun daripada en-GB 6.2.0) **Diterjemah oleh / Translated by:** Saifuddin dengan Claude AI — t.me/joomlamalaysia

## Apa yang ada / What's included

- 2,499 rentetan bahagian hadapan (73 fail) dalam Bahasa Melayu.
- Senarai perkataan Malay untuk Smart Search.
- Metadata bahasa: `ms-MY`, Bahasa Melayu (Malaysia), arah kiri-ke-kanan.

## Pilihan istilah / Terminology choices

| English | Bahasa Melayu |
| --- | --- |
| Image | Gambar |
| Caption | Sari Kata |
| Contact | Kenalan |
| Hits | Paparan |
| Log in / Log out (buttons) | Masuk / Keluar |
| Log in (headings) | Log Masuk |
| Enabled / Disabled | Dihidupkan / Dimatikan |
| Blocked (account) | Digantung |
| Check-in / Check-out | Daftar masuk / Daftar keluar |
| Configuration | Tatarajah |
| Password reset | Penetapan semula kata laluan |
| New | Baharu |

Nada dilembutkan untuk pengguna bukan teknikal: *mesti* → *perlu*, *tidak dibenarkan* → *tidak mempunyai kebenaran*, *Ralat* → *Masalah* pada mesej untuk pengunjung.

## Had yang diketahui / Known limitations

- Hanya bahagian hadapan (site). Pek pentadbir (backend) akan menyusul jika ada permintaan.
- Belum disemak oleh penutur asli dan belum diuji pemasangannya oleh penterjemah. Uji di laman staging dahulu.
- Mesej teknikal (pemasang, pangkalan data, sistem fail) masih menggunakan "Gagal" / "Ralat".
